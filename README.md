# เว็บคอร์สเรียนออนไลน์ (ล็อกด้วยรหัสผ่าน)

โปรเจกต์ Next.js สำหรับลงคอร์สวิดีโอของคุณ เข้าเรียนได้เฉพาะคนที่มีรหัสผ่านเท่านั้น
โดเมนและหน้าตาเป็นของคุณเองทั้งหมด ไม่ผูกกับแพลตฟอร์มใด ใช้ฟรีบน Vercel ได้

## โครงสร้าง

- `/` — หน้าแนะนำคอร์ส (เปิดดูได้ทุกคน)
- `/login` — หน้ากรอกรหัสผ่าน
- `/learn/[บทเรียน]` — หน้าดูวิดีโอ (เข้าได้เฉพาะคนที่ล็อกอินแล้ว)
- `lib/lessons.ts` — ข้อมูลคอร์สและบทเรียนทั้งหมด แก้ตรงนี้ที่เดียวพอ

## แก้ไขเนื้อหาคอร์ส

เปิดไฟล์ `lib/lessons.ts` แล้วแก้:
- `courseTitle`, `instructor` — ชื่อคอร์สและผู้สอน
- `lessons` — รายการบทเรียน แต่ละบทมี `title`, `duration`, `videoUrl`, `description`, `points`

**ใส่ลิงก์วิดีโอของคุณเอง (`videoUrl`)** ทำได้ 2 แบบ:
1. **YouTube แบบ Unlisted** — อัปโหลดวิดีโอ ตั้งค่าเป็น "ไม่แสดงสาธารณะ" แล้วใช้ลิงก์แบบ embed
   เช่น `https://www.youtube.com/embed/รหัสวิดีโอ`
2. **ไฟล์วิดีโอของตัวเอง** — อัปโหลดไฟล์ mp4 ไว้ที่ไหนก็ได้ (เช่น Vercel Blob, Cloudflare R2, Bunny.net)
   แล้วเปลี่ยนแท็ก `<iframe>` ในไฟล์ `app/learn/[slug]/page.tsx` เป็น `<video controls src="ลิงก์ไฟล์" />`

## รันทดสอบในเครื่องตัวเอง

```bash
npm install
cp .env.example .env.local
# แก้ .env.local ใส่รหัสผ่านที่ต้องการ
npm run dev
```

เปิด http://localhost:3000

## Deploy ขึ้น Vercel

1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo (หรือลาก-วางทั้งโฟลเดอร์เข้า Vercel ก็ได้ ผ่านปุ่ม "Add New Project")
2. ไปที่ [vercel.com](https://vercel.com) → **Add New Project** → เลือก repo นี้
3. ก่อนกด Deploy ให้ตั้งค่า **Environment Variables**:
   - `COURSE_PASSWORD` = รหัสผ่านที่จะแจกให้ผู้เรียน
   - `COURSE_SESSION_SECRET` = ข้อความสุ่มยาวๆ อะไรก็ได้ (ใช้ครั้งเดียวตอน deploy ไม่ต้องจำ)
4. กด Deploy รอสักครู่ เสร็จแล้วจะได้ลิงก์ เช่น `your-course.vercel.app`

เปลี่ยนรหัสผ่านทีหลังได้ทุกเมื่อ โดยไปแก้ค่า `COURSE_PASSWORD` ใน Vercel → Settings → Environment Variables
แล้วกด Redeploy หนึ่งครั้ง

## ข้อควรรู้เรื่องความปลอดภัย

ระบบนี้เป็น "รหัสผ่านเดียวใช้ร่วมกัน" (shared password) เหมาะกับการกันคนทั่วไปเดินผ่านมาดูฟรีๆ
แต่ไม่ใช่ระบบสมาชิกรายบุคคล — ถ้ามีคนแชร์รหัสต่อ คนอื่นก็เข้าดูได้เหมือนกัน
ถ้าต้องการระบบล็อกอินแยกเป็นรายคน (รู้ว่าใครเรียนไปถึงไหน, เปิด/ปิดสิทธิ์รายคนได้)
จะต้องเพิ่มฐานข้อมูลผู้ใช้ ซึ่งเป็นขั้นถัดไปที่ทำเพิ่มได้ภายหลัง
